# Architecture Decision Records (ADR)

Niniejszy folder zawiera rekordy decyzji architektonicznych (ADR) dla projektu 67Bet. 
ADR to krótki dokument tekstowy opisujący istotną decyzję architektoniczną, jej kontekst oraz konsekwencje.

## Spis Rekordów

*   [ADR 0001: Wprowadzenie do ADR](0001-record-architecture-decisions.md) - Podstawowe informacje o formacie i celu stosowania ADR.
*   [ADR 0002: Weryfikacja KYC przy użyciu SignalR](0002-kyc-signalr-verification.md) - Decyzja o sposobie komunikacji między urządzeniem desktop i mobile w procesie KYC.
